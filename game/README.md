# game/

**EN** — `instalar.sh` / `instalar.cmd` extract **your own** God of War (USA, `SCUS-97399`) ISO here. Nothing in this
folder is ever uploaded (see `.gitignore`).

**TR** — `instalar.sh` / `instalar.cmd`, **kendi** God of War (ABD, `SCUS-97399`) ISO'nuzu buraya açar. Bu klasördeki
hiçbir şey depoya yüklenmez (`.gitignore`).

**ES** — `instalar.sh` / `instalar.cmd` extraen aquí la ISO de **tu propia copia** de God of War (EE. UU.,
`SCUS-97399`). Nada de esta carpeta se sube al repositorio (`.gitignore`).
